## 본문

**문제 상황**
sh-api 브랜치를 실행하였으나 에러가 발생하며 서버가 종료되는 문제 발생  
```
Error creating bean with name 'jwtProvider': Injection of autowired dependencies failed; nested exception is java.lang.IllegalArgumentException: Could not resolve placeholder 'JWT.SECRET' in value "${JWT.SECRET}"
```


**원인**
Value 어노테이션 내의 "${JWT.SECRET}" 값을 가져오지 못해 발생한 문제. 이는 value로 application_key.properties 파일을 참조하였으나, 해당 파일이 .gitignore에 기재되어 있어 application_key.properties 파일이 업데이트 되지 못해 생긴 문제이다.   



**해결방법**
@sssh22 의 application_key.properties 파일에서 발생한 수정사항을 전체 파일에 반영해야 한다.
