![image](https://github.com/user-attachments/assets/270b4377-31ce-4835-baad-5008050f6626)  

Gradle이 실제로 컴파일할 때 사용하는 JDK 버전이 시스템에 설정된 JDK 버전 또는 Gradle Toolchain에 의해 결정된다. 
다음 사항을 확인하라 
- IDE에서 JDK 설정 확인: 프로젝트 SDK와 Gradle JVM 설정이 모두 JDK 17로 맞춰져 있는지 확인
- 시스템 환경변수 확인: 시스템 환경 변수(JAVA_HOME)이 JDK 17을 가리키고 있는지 확인

### jisoo449 (2024-08-14T05:53:11Z)

## 원인 및 해결방법
- 로컬에서 build 시 생겼던 문제는 JAVA_HOME 환경변수가 jdk-21로 설정되어 있어서 발생했던 문제이다. 해결함.
- build 할 때 compile querydsl 이런 문제 생겼던 거는 paintDetailDto가 unversioned되어 발생한 문제. 해당 파일을 커밋 후 푸시하여 해결
- 스프링부트 2.6 이상은 PathPatternParser를 사용하는데, swagger를 위한 springfox는 AntPathMatcher를 사용. application.properites를 수정하여 AntPathMatcher사용하도록 수정
