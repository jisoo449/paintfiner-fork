## 본문

## 설명
코드빌드 생성 후 실행 중 다음과 같은 오류가 발생하였다.
```log
ACCESS_DENIED: Service role arn:aws:iam::866999263719:role/service-role/codebuild-paintfinder-backend-codebuild-service-role does not allow AWS CodeBuild to create Amazon CloudWatch Logs log streams for build arn:aws:codebuild:ap-northeast-2:866999263719:build/paintfinder-codebuild-be:5d6b1699-6ee7-4f25-af44-123e9ba703e9. Error message: User: arn:aws:sts::866999263719:assumed-role/codebuild-paintfinder-backend-codebuild-service-role/AWSCodeBuild-5d6b1699-6ee7-4f25-af44-123e9ba703e9 is not authorized to perform: logs:CreateLogStream on resource: arn:aws:logs:ap-northeast-2:866999263719:log-group:/aws/codebuild/paintfinder-codebuild-be:log-stream:5d6b1699-6ee7-4f25-af44-123e9ba703e9 because no identity-based policy allows the logs:CreateLogStream action
```
![image](https://github.com/user-attachments/assets/d4789ffd-bc27-4128-b120-9fc61a9f228c)


## 해결
위 문제는 AWS CodeBuild 서비스 역할(service role)에 CloudWatch Logs 권한 누락으로 발생하였다.  
CodeBuild는 빌드 로그를 CloudWatch Logs에 기록하려고 시도했으나, logs:CreateLogStream 작업에 대한 권한이 없어 실패한 상황이다.  

다음 과정을 수행하라.   

1. AWS Management Console에서 IAM 역할 수정  
    CodeBuild 역할을 찾아 CloudWatchLogsFullAccess 혹은 AWSCodeBuildDeveloperAccess 권한을 추가하라.
