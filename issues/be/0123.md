## 본문

## 설명
현재 Elastic Beanstalk는 HTTP 통신만 가능하다. 이를 수정하여 HTTPS 통신도 가능하게 하라.

## 해결방법
엘라스틱 빈스토크를 온디맨드 형식으로 구현하였다면 로드밸런서에 443 리스너를 추가하는 방식 만으로 문제 해결이 가능하다.  
하지만 스팟 인스턴스로 엘라스틱 빈스토크를 구현하였기 때문에 스프링부트 애플리케이션 내에서 HTTPS 설정을 활성화해야 한다.  
HTTPS 통신을 위한 SSL 인증서의 발급이 필요하다. ACM은 로드밸런서에만 적용할 수 있으므로 여기에서는 사용하지 못한다.  
Elastic Beanstalk의 Nginx 서버는 Spring Boot의 proxy 역할을 한다. 따라서 

1. Elastic Beanstalk 환경의 도메인을 Route53을 통해 설정  
    Route 53에 생성한 도메인으로 들어가서 레코드 생성을 누른다.
    ![image](https://github.com/user-attachments/assets/6b8d8bdc-73be-49e4-adc3-014a41cf944a)  
    값에는 elastic beanstalk의 url을 넣는다.
    ![image](https://github.com/user-attachments/assets/b8560e59-4409-4442-8f99-69a635abacbd)  

2. Elastic Beanstalk에 접속하여 nginx conf 수정
    ``` bash
    sudo nano /etc/nginx/conf.d/elasticbeanstalk/00_application.conf
    ```
    ```shell
    ### 파일 하단에 아래 내용 추가
    location /.well-known/acme-challenge/ {
        root /var/www/html; # 인증 파일 저장 경로
        default_type "text/plain";
    }
    ```
    ```bash
    ## nginx 재시작
    sudo systemctl restart nginx
    ```

3. SSL 인증서 발급
    ```bash
    sudo yum update
    sudo yum install certbot
    sudo certbot certonly --webroot -w /var/www/html -d eb.paintfinder.art
    ```

4. 프로젝트의 루트에 `.platform/nginx/conf.d/ssl_custom.conf` 파일 생성
    ```config
    server {
        listen 443 ssl;
        server_name eb.paintfinder.art;
    
        ssl_certificate /etc/letsencrypt/live/eb.paintfinder.art/fullchain.pem;
        ssl_certificate_key /etc/letsencrypt/live/eb.paintfinder.art/privkey.pem;
    
        location / {
            proxy_pass http://127.0.0.1:5000; # Spring Boot 등 애플리케이션 서버
            proxy_http_version 1.1;
    
            proxy_set_header Connection $connection_upgrade;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
    
    server {
        listen 80;
        server_name eb.paintfinder.art;
    
        location /.well-known/acme-challenge/ {
            root /var/www/html;
            default_type "text/plain";
        }
    
        return 301 https://$host$request_uri; # HTTP → HTTPS 리디렉션
    }
    ```

5. Let's Enrypt 인증서 자동 갱신 설
    ```
    sudo crontab -e
    0 3 * * * certbot renew --quiet --deploy-hook "systemctl restart tomcat"  # Spring Boot 서비스 재시작
    ```
