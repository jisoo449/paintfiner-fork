## 본문

## 설명
Elastic Beanstalk로 설정 후 생성된 url로 접속할 때 502 Bad Gateway 에러가 발생하였다.

## 해결
Elastic beanstalk로 생성된 ec2에 접속하여 /var/log/nginx/error.log 파일을 보았다.

애플리케이션 로드 밸런서가 기본적으로 EC2 인스턴스에서 nginx 서버의 80번 포트를 가리키고, nginx가 기본적으로 포트 5000의 요청을 전달하도록 구성되어 있기 때문에 발생하는 문제이다.  

환경 클릭 후 좌측 사이드바에서 구성을 클릭한다.
![image](https://github.com/user-attachments/assets/56adae71-2264-433d-a030-f31562e19bfe)  

업데이트, 모니터링 및 로깅을 찾아 편집 버튼을 클릭한다.
![image](https://github.com/user-attachments/assets/16a940a3-cfaf-4c8a-86c8-61b7e13d9c27)  

환경 속성에서 SERVER_PORT, 5000을 추가한다.
![image](https://github.com/user-attachments/assets/423991df-626e-47a8-9ce0-654a88f798bb)
