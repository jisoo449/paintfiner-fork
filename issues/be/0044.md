위 사이트를 참고하여 서비스를 구현하던 중 KAKAO_CLIENT_SECRET이 무엇을 의미하는지 의문이 생김

## 해결
#### • KAKAO_CLIENT_SECRET
카카오 개발자 사이트에서 애플리케이션을 생성하고 설정한 후에 받아올 수 있는 값이다.  
다음과 같은 방식으로 값을 설정하고 가져올 수 있다.  
1. 카카오 개발자 사이트 접속  
   카카오 개발자 사이트(https://developers.kakao.com) 에 접속하여 로그인합니다.

2. 애플리케이션 생성
   상단 메뉴에서 "내 애플리케이션"을 클릭합니다.  
   "애플리케이션 추가하기" 버튼을 클릭하여 새로운 애플리케이션을 생성합니다.
   애플리케이션 이름과 사업자명(또는 개인)을 입력하고 "저장"을 클릭합니다.  

3. 애플리케이션 설정  
   생성한 애플리케이션을 선택합니다.  
   왼쪽 메뉴에서 "설정" -> "일반"을 클릭합니다.  
   "REST API 키", "JavaScript 키", "Admin 키" 등이 표시됩니다.  

4. 카카오 로그인 설정  
   왼쪽 메뉴에서 "제품 설정" -> "카카오 로그인"을 클릭합니다.  
   "Redirect URI"를 설정합니다. 이는 사용자가 카카오 로그인을 완료한 후 리디렉션될 URI입니다.  
   예: http://yourdomain.com/oauth  
   "저장"을 클릭합니다.  

5. Client Secret 설정  
   "카카오 로그인" 설정 페이지에서 "보안 설정" 항목을 찾습니다.  
   "Client Secret"을 활성화합니다. 이 기능을 활성화하면 client_secret가 생성됩니다.  
   생성된 client_secret 값을 복사하여 안전한 장소에 저장합니다.
