## 설명
새로운 환경에서 프로젝트 빌드 시 아래와 같은 오류 발생  
![Image](https://github.com/user-attachments/assets/2363b75b-4d94-4b0c-a007-914d7fd55cf4)

## 원인
Gradle이 Java17을 지원하지 않는 JDK버전을 사용

## 해결방법
1. 자바 버전 확인  
    ```
    경로 > ./gradlew --version                                                                                                   
                                                                                                                                                                
    ------------------------------------------------------------
    Gradle 7.5.1
    ------------------------------------------------------------
    
    Build time:   2022-08-05 21:17:56 UTC
    Revision:     d1daa0cbf1a0103000b71484e1dbfe096e095918
    
    Kotlin:       1.6.21
    Groovy:       3.0.10
    Ant:          Apache Ant(TM) version 1.10.11 compiled on July 10 2021
    JVM:          1.8.0_431 (Oracle Corporation 25.431-b10)
    OS:           Windows 11 10.0 amd64
    ```  
    gradlew 명령어로 살펴본 결과 Java8 버전을 사용하는 것을 확인하였다.
    프로젝트 조건에 맞는 Java17을  설치, 빌드하자.  

2. JAVA 17.0.10 설치
    https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html  
    위 사이트 접속 후 원하는 버전, OS, 사양에 맞는 자바 다운로드  
 
3. 파일>프로젝트 구조>SDK 설정으로 들어가 java17 추가. 
4. 프로젝트 SDK 자바 17로 수정
5. crtl+art+s 눌러서 언어 java17로 수정

6. 프로젝트 빌드
