## 해결방법
중계테이블로 연결된 데이터(피그먼트, 사이즈)를 가져오기 위해 DTO를 만들었는데, 해당 DTO에 대한 생성자가 정의되어 있지 않아 발생한 문제로 보인다. 따라서 각각의 DTO에 대해 생성자를 추가 해 주었다.  
```
@Data
@NoArgsConstructor
public class PigmentForPaintDto {
    @Setter(AccessLevel.NONE)
    private int pigmentIdx;
    private String ciName;

    @QueryProjection
    public PigmentForPaintDto(int pigmentIdx, String ciName){
        this.pigmentIdx = pigmentIdx;
        this.ciName = ciName;
    }
}
```

<br/>

또한 생성자의 파라미터 순서와 select 결과가 일치해야 한다. 만약 일치하지 않는다면 위에 설명한 문제가 동일하게 나타난다.  
따라서 컬럼을 select하는 순서와 dto의 생성자 파라미터가 받는 순서를 일치하게 만들었다.
