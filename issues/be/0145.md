## Description

![Image](https://github.com/user-attachments/assets/d2767198-b84d-48c2-a85c-235e4ddaddab)

groupby.list로 DB 조회 결과를 다중 list로 감싸는 중, pigment 에서 IllegalArgumentException 발생.
PaintInMyPaletteRepositoryDto 와 Pigment 의 속성 자료형이 다르거나, groupby 자체에서 문제가 있을 것으로 예상.


아예 코드 구조 변경으로 문제 해결.

구현 순서
1. List<Integer> randomPaletteIds에 포함된 myPalIdx 값을 기준으로 팔레트 정보 조회
- List<RandomMyPaletteRepositoryDto>를 생성
- paintList는 빈 값으로 둠
2. Palette_Paint 테이블에서 myPalIdx에 해당하는 페인트 목록 조회
- 조회한 값을 paintList에 저장
- pigments 값은 빈 리스트로 둠
3. paintList에 있는 paintIdx를 기준으로 Paint_Pigment 테이블에서 안료 정보 조회
- 조회한 값을 paintList 안의 pigments 리스트에 저장
