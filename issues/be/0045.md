## 추가로 한 방법
### 1. 깃헙 러너 서비스로 돌아가게 만들기
1. 유닛 파일 생성  
   sudo nano /etc/systemd/system/my-docker-app.service  

2. 유닛 파일 내용 작성
```
[Unit]
Description=GitHub Runner Service
After=network.target

[Service]
ExecStart=/bin/bash /home/username/scripts/run.sh
Restart=always
User=username
WorkingDirectory=/home/username/scripts

[Install]
WantedBy=multi-user.target
```  

4. 유닛 파일 권한 설정
   ```
   sudo chmod 644 /etc/systemd/system/my-docker-app.service
   ```  

5. 데몬 리로드
   ```
   sudo systemctl daemon-reload
   ```

6. 서비스 시작 및 활성화
   ```
   sudo systemctl start my-docker-app.service
   sudo systemctl enable my-docker-app.service
   ```

### 2. 도커 컴포즈
1. 도커 컴포즈 설치 : https://docs.docker.com/compose/install/linux/#install-using-the-repository
2. 도커 컴포즈 파일 생성 (파일명: docker-compose.yml)
    ``` docker-compose.yml
    version: '설치한 도커 버전'
    services:
       app:
            image: 실행할 도커 이미지 이름
            ports:
                - "8080:8080"
            restart: always
    ```
3. 도커 컴포즈 실행
    ```
    $ docker compose up -d
    ```  

위 과정을 거치면 인스턴스를 재부팅해도 도커가 실행된다.
