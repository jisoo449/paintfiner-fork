추가적으로, Systemd에 서비스 파일을 생성하고, 데몬을 리로드하여 생성한 데몬이 enable하게 실행되도록 서버를 설정 해 주어야 한다.  

1. /etc/systemd/system/my_docker_compose.service 파일을 생성
   ```
   sudo nano /etc/systemd/system/my_docker_compose.service
   ```  

2. 서비스 파일 설정
   ```
   [Unit]
   Description=Docker Compose Application Service
   After=network.target docker.service
   Requires=docker.service
   
   [Service]
   Restart=always
   WorkingDirectory=/home/ubuntu
   ExecStart=/usr/local/bin/docker-compose up -d
   ExecStop=/usr/local/bin/docker-compose down
   
   [Install]
   WantedBy=multi-user.target
   ```  

3. 서비스 시작 및 활성화
   ```
   sudo systemctl daemon-reload
   sudo systemctl start my_docker_compose
   sudo systemctl enable my_docker_compose
   ```
