 PaintService를 사용하는 CommonController에서 에러가 발생하였다.  

## 원인
위의 에러 중 핵심이 되는 에러 내용은 다음과 같다.
```
cannot simultaneously fetch multiple bags: [com.paintfinder.paint.entity.Paint.setsPaintList, com.paintfinder.paint.entity.Paint.pigment_list, com.paintfinder.paint.entity.Paint.paintSizeList]
```  
cannot simultaneously fetch multiple bags 오류는 Hibernate에서 다중 컬렉션을 한 번에 페치 조인(fetch join)할 때 발생하는 문제를 의미한다. 즉, Hibernate가 여러 bag(One to many)을 한번에 로드할 수 없어 발생한 문제이다.  

Hibernate는 다중 컬렉션을 한 번에 페치 조인할 때 각 컬렉션에 대해 별도의 SQL 쿼리를 생성하는데, 여러 개의 컬렉션을 동시에 페치 조인하면 Hibernate는 이 컬렉션들 간의 관계를 제대로 관리하지 못하여 cannot simultaneously fetch multiple bags 오류가 발생하게 된다.(N+1 문제)  

## 해결
다음과 같은 방법들을 시도해볼 수 있다.  
#### 1. 엔티티 설계 변경
여러 컬렉션을 동시에 페치 조인하지 않도록 엔티티 설계를 변경할 수 있습니다.
#### 2. batchSize 사용
@BatchSize 어노테이션을 사용하여 지정된 사이즈만큼의 데이터를 한번에 조회한다.  
#### 3. 서브쿼리 사용
여러 개의 페치 조인을 피하기 위해 필요한 데이터를 서브쿼리로 가져옵니다.
#### 4. DTO를 사용해 쿼리
필요한 데이터를 직접 쿼리하여 DTO(Data Transfer Object)에 매핑한다. 즉, QueryDSL을 사용한다.

이 중 선택한 방법은 **4. DTO를 사용해 쿼리** 이다. 
자세한 해결 방법은 PaintRepositoryImpl의 코드를 참고하도록.
