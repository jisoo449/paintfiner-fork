## 해결방법
redis-host를 localhost로 설정하였다. 도커 컨테이너에서 localhost는 컨테이너 내부를 가리킨다. 실제 redis는 스프링부트 프로젝트가 돌아가는 컨테이너가 아닌 ec2 서버 내에서 돌아가므로 localhost를 입력하였을 때 제대로된 주소로 매핑되지 못한다. 따라서 해당 주소를 localhost에서 백엔드 서버의 ip주소로 변경 해 주어야 한다.

## 1. redis.conf 수정
### 1.1. bind하는 IP 수정
컨테이너는 redis에 서버와 private ip주소를 통해 통신한다. 따라서 redis의 conf 파일에서 bind 할 ip를 ec2의 private ip로 설정하자.

### 1.2. 비밀번호 설정

## 2. 스프링 프로젝트 수정
### 2.1. properties 파일에 host 수정 및 password 추가
컨테이너와 서버의 redis는 서버의 private IP로 통신한다. 따라서 application_key.properties 파일의 REDIS_HOST를 localhost에서 ec2의 private ip로 수정하자.  
또한 비밀번호를 설정 해 주었으므로 password를 추가 해 주어야 한다.
```
# application_key.properties
REDIS_HOST=ec2서버의 private ip 주소
REDIS_PASSWORD=redis의 비밀번호
```

```
# application.properties
spring.data.redis.host=${REDIS_HOST}
spring.data.redis.port=6379
spring.data.redis.password=${REDIS_PASSWORD}
```

### 2.2. RedisConfig.java 수정
redis의 password가 추가되었으므로 해당 변수를 추가 생성해 주자.  
LettuceConnectionFactory를 사용해 redis 서버와의 연결을 설정해야 하지만, 해당 메서드는 password를 넣을 수 있는 매개변수가 존재하지 않기 때문에 RedisStandaloneConfiguration 객체를 생성하여 redis 서버의 정보를 캡슐화하여 해당 메서드에 넘겨주는 방식으로 코드를 작성해야 한다.
```
    @Value("${spring.data.redis.host}")
    private String redisHost;
    @Value("${spring.data.redis.port}")
    private int redisPort;
    @Value("${spring.data.redis.password}")
    private String redisPassword;

    /**
     * Redis 연결을 위한 RedisConnectionFactory 생성 (Redis 클라이언트로 Lettuce 사용)
     */
    @Bean
    public RedisConnectionFactory redisConnectionFactory(){
        RedisStandaloneConfiguration redisStandaloneConfiguration = new RedisStandaloneConfiguration();
        redisStandaloneConfiguration.setHostName(redisHost);
        redisStandaloneConfiguration.setPort(redisPort);
        redisStandaloneConfiguration.setPassword(redisPassword); // 비밀번호 설정

        return new LettuceConnectionFactory(redisStandaloneConfiguration); // .properties 파일에서 설정한 host, port 가져와 연동
    }
```
