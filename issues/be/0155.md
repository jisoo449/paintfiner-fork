## 본문

![Image](https://github.com/user-attachments/assets/9b267422-63c4-44ef-8b85-85be2b5ff5d9)
기존의 코드(MockMultipartFile) 을 사용했을 시 import 하지 못하는 문제 발생.

이왕 문제가 발생한 것, mockMultipartFile 은 테스트용으로 사용되는 라이브러리이기에
CommonsMultipartFile 라이브러리로 교체하기로 함.

gradle 파일에
`implementation 'commons-fileupload:commons-fileupload:1.4'`
를 추가

FileUtil.java 파일에서 MockMultipartFile 사용하던 부분을 CommonsMultipartFile로 교체하여 해결하였음.


> gradle implements 문 추가 시 항상 해야할것
gradle refresh, gradle clean, gradle build 순으로 gradle 파일을 최신화해주자.
