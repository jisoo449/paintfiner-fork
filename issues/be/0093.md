## 해결방법
기존의 left join을 사용해 중계 테이블을 연결하고, 데이터를 후처리하여 paintThumbnail을 가져오는 방법은 복잡한 작업을 가능하게 하는 QueryDSL을 사용하는 용도에 맞지 않았다. (이럴거면 차라리 JPQL을 써)  

List로 된 데이터를 가져오는 방법으로 QueryFactory의 transform을 사용해 중복 데이터로 인해 발생할 수 있는 offset 불일치 문제를 해결하였다.
```
.transform(GroupBy.groupBy(paint.paintCode).list(
                                                new QPaintThumbnailDto(
                                                        paint.paintCode,
                                                        paint.brandEN,
                                                        paint.brandKR,
                                                        paint.paintNameEN,
                                                        paint.paintNameKR,
                                                        paint.colorEN,
                                                        paint.colorKR,
                                                        paint.sizes,
                                                        paint.textureImg1,
                                                        paint.prodImg,
                                                        GroupBy.list(new QPigmentForPaintDto(
                                                                pigment.pigmentIdx,
                                                                pigment.ciName
                                                        ))
                                                )
                                        ))
```  
또한 안료의 기본값이 버려지지 않고 그대로 정보에 저장되는 문제는 자바의 removeIf 메서드를 활용하여 O(n)의 시간복잡도로 해결하였다.
```
pigments.removeIf(pig -> pig.getPigmentIdx() == 0 && pig.getCiName() == null);
```  

위와 같이 코드를 개선하며 데이터 후처리에 걸리던 48줄의 코드를 삭제하여 코드를 더욱 간결하게 작성할 수 있었다.
