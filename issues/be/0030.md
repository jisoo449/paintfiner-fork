## 본문

**설명**
paint controller 를 실행하던 도중 아래와 같은 에러가 발생하였다.  

     Null value was assigned to a property [class com.paintfinder.paint.entity.Paint.quality]
     of primitive type setter of com.paintfinder.paint.entity.Paint.quality; 


**원인**
int, boolean, char, byte, short, long, float, double 등과 같은 타입을 원시타입이라 한다. 이러한 원시타입은 Null값을 가질 수 없다. 하지만 Paint의 Entity에서 int 타입을 가지는 변수에 Null값을 할당하여 위와 같은 문제가 발생하였다.  


**해결방법**
Paint의 Entity 내에서 int로 설정된 변수 타입을 Integer로 수정하였다.
