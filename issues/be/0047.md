## 발생 문제 -> JPA 어노테이션 에러
스프링 부트 버전을 2에서 3으로 업그레이드 하면서 @Entity, @Id, @Column, @OneToMany, @ManyToOne, @JoinColumn, @GeneratedValue 등의 어노테이션에서 에러가 발생하였다.  
이는 JPA와 관련된 클래스들이 javax.persistenence 에서 jakarta.persistence 패키지로 변경되었기 때문이다. 따라서 해당 패키지를 사용하는 모든 코드를 변경 해 주어야 한다.   
```
javax.persistence.* ➔ jakarta.persistence.*
javax.validation.* ➔ jakarta.validation.*
javax.servlet.* ➔ jakarta.servlet.*
javax.annotation.* ➔ jakarta.annotation.*
javax.transaction.* ➔ jakarta.transaction.*
```  

참고: https://covenant.tistory.com/279  

<br/>
만약 jakarta 패키지를 찾지 못한다면 프로젝트를 다시 빌드해야 한다.
