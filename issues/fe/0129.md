# 1. 상황 설명
![Image](https://github.com/user-attachments/assets/2d6a5838-b639-4981-b03a-c7f9c66dfa07)
물감 검색 페이지로 이동 시  
```
GET https://paintfinder.art/paint/paintFinderLogo.ico 404 (Not Found)
```
라는 오류 메시지가 발생하며 검색 결과 로딩이 불가하다.

# 2. 원인
~~`/public/index.html` 파일에서 아이콘을 불러오는 경로가 `%PUBLIC_URL%/paintFinderLogo.ico`, `%PUBLIC_URL%/logo192.png` 이다.~~  
~~AWS Code Amplify 서비스에서 프론트의 코드를 실행할 때 해당 경로를 제대로 파악하지 못한 것이 원인으로 추정된다.~~

추정 원인은 물감 검색 파트의 기능이 미흡하게 구현된 것으로 추정된다.  
이를 해결하기 위해서는 두 가지를 확인해야 한다.  
- FE와 BE의 물감 요청-응답 데이터 구조가 동일하게 구성되었는가
- 안료가 중복되어 표기되는 부분이 상관이 있지는 않는가
----
확인 결과, filter state의 값이 제대로 초기화가 되지 않은 것을 확인할 수 있다.  
![Image](https://github.com/user-attachments/assets/66f4c9be-b8b7-42b8-aeb6-2fb01909f741)

<br/>
또한, 검색 결과의 개수가 이상한 것을 확인할 수 있다.  

![Image](https://github.com/user-attachments/assets/63cc344f-c245-482f-abd8-b947a17d0f5d)

# 3. 해결방법
- 카테고리 버튼 클릭 시 마다 filter state 초기화 하도록 onClick 이벤트 삽입

# 해결해야 할 문제
- [ ] 물감 검색 페이지에서 검색어 입력 시 url 안바뀜
- [ ] 카테고리 클릭 시 페이지 및 필터 아톰 초기화 안됨
