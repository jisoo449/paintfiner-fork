## 문제상황
- Function Error: destroy is not a function  
  → useEffect 내 함수를 제대로 작성하지 않아 생긴 문제   
      ```useEffect(()=>함수명,[])``` 이 아니라, ```useEffect(()=>{함수명},[]}``` 처럼 작성해야 한다.   
- 새로고침 시 모달 유지
  → 페이지 새로고침 상태를 만듦. 이후 기본으로 호출되는 useEffect 함수에서 해당 값을 변경함.   
      이후 다른 useEffect 함수에서 조건문을 사용해 해당 상태가 초기값이 아니라면 특정 동작을 수행하게 함.
