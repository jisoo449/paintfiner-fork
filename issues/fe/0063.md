## 설명
![image](https://github.com/paint-finder/webui/assets/48276691/10f4b512-2248-460b-8a73-cf58449c2ad0)
화살표를 눌러도 새로운 사진이 나오지 않음

## 원인
```
    useEffect(()=>{
        fetchData();
    })
```
useEffect가 다음과 같이 작성되어 있었다. 이 때문에 페이지가 계속 리렌더링 되면서 사진이 이동이 되지 않았던 것

## 해결
```
    useEffect(()=>{
        fetchData();
    },[])
```
다음과 같이 코드 작성
