## 1. 도메인 연결
### 1.1 EC2 생성
ec2: 10GB, t3.small
도메인: paintfinder.art

### 1.2 Elastic IP 할당
1. AWS Management Console에서 EC2 대시보드로 이동합니다.  
2. "Elastic IPs"를 선택합니다.
5. "Allocate Elastic IP address"를 클릭합니다.
6. Elastic IP 주소를 생성하고, 해당 주소를 EC2 인스턴스에 할당합니다.

### 1.3. Route 53에서 호스팅 영역 생성
1. AWS Management Console에서 Route 53 대시보드로 이동합니다.
2. "Hosted zones"를 선택합니다.  
3. "Create Hosted Zone"을 클릭합니다.  
    ![image](https://github.com/paint-finder/webui/assets/48276691/4de920bf-3ece-44ad-98eb-2f5f243ad7e6)   
4. 도메인 이름을 입력하고, 호스팅 영역을 생성합니다.  
   ![image](https://github.com/paint-finder/webui/assets/48276691/c9949232-1611-4f73-8e8f-e247f7f18bf8)  

### 1.4. DNS 레코드 생성
1. 생성된 호스팅 영역으로 이동합니다.
   ![image](https://github.com/paint-finder/webui/assets/48276691/a7fc2252-a066-43d8-99a2-ab4ff3717145)  
2. "Create Record Set"을 클릭합니다.
3. A 레코드 또는 CNAME 레코드를 추가하여 도메인을 EC2 인스턴스의 Elastic IP 주소에 연결합니다.  
    A 레코드 설정 예시:  
      - Name: (빈칸으로 두거나 www와 같은 서브도메인 입력)
      - Type: A - IPv4 address
      - Value: Elastic IP 주소  
   ![image](https://github.com/paint-finder/webui/assets/48276691/b33b1487-ef7f-4649-a9cd-3db35b9aa077)

## 2. 도커 이미지 띄우기
참고: https://velog.io/@songheechoi/Docker-react-nginx-Dockerizing-%EC%9D%B4%EC%9A%A9%ED%95%B4-%EB%A6%AC%EC%95%A1%ED%8A%B8-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8-%EB%B0%B0%ED%8F%AC%EC%8B%9C%EB%8F%84-1

### 2.1. 리액트 빌드 파일 생성
```
npm run build
```

### 2.2. nginx.conf 파일 루트 경로에 생성
```
server {
    listen 80;

    server_name localhost;

    location / {
        root /build/static;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    error_page 500 502 503 504 /50x.html;
    location = /50x.html {
        root /usr/share/nginx/html;
    }
}
```

### 2.3. 도커파일 생성
```
# Step 1: 리액트 애플리케이션 빌드
From node:20 AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production 
COPY . .
RUN npm run build

# Step 2. Nginx 설정 및 리액트 애플리케이션 serve
FROM nginx:1.25.0-alpine as production
COPY --from=build /app/build /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### 2.2. 레포지토리 생성 후 도커파일 빌드 및 푸시
```
docker build -t 계정이름/레포지토리이름:태그 .
docker push 계정이름/레포지토리이름:태그
```
