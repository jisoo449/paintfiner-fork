## 본문

## 문제 상세 설명
```Dockerfile
#Dockerfile
# Step 1: 리액트 애플리케이션 빌드
From node:20 AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production 
COPY . .
RUN npm run build

# Step 2. Nginx 설정 및 리액트 애플리케이션 serve
FROM nginx:1.25.0-alpine as production
COPY --from=build /app/build /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```  

```nginx.conf
#nginx.conf
server {
    listen 80;

    server_name localhost;

    location / {
        root /build/static
        index index.html
        try_files $uri $uri/ /index.html;
    }

    error_page 500 502 503 504 /50x.html;
    location = /50x.html {
        root /usr/share/nginx/html;
    }
}
```
위와 같이 도커파일과 nginx.conf 파일을 만들고 도커 이미지를 build한 뒤 실행하였으나 root에 들어가는 arguments가 invalid하다는 오류가 발생하였다.

## 성공한 해결책
root에 arguments가 invalid한 값으로 들어갔다는 에러 메시지가 나온 이유는 코드를 ';'으로 마치지 않았기 때문이다. 
해당 부분에 세미콜론을 추가하여 문제를 해결하였다.
```
//nginx.conf
server {
    listen 80;

    server_name localhost;

    location / {
        root /build/static;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    error_page 500 502 503 504 /50x.html;
    location = /50x.html {
        root /usr/share/nginx/html;
    }
}
```
