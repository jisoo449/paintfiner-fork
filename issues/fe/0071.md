## 본문

## 설명 
App.js에서 PaintDetail 페이지의 파라미터를 paintId로 설정하였다.  
```
{ path: "/paintDetail/:paintId", element: <PaintDetail /> },
```

이후 PaintDetail 페이지에서 useParams()를 사용해 파라미터를 가져올 때 paintId가 아닌 paintCode로 가져오려 하였다.
```
const { paintCode } = useParams();
```

이 때문에 해당 파라미터를 통해 GET 요청을 보낼 때 제대로된 파라미터가 전달되지 않는 문제가 발생하였다.  

이를 해결하기 위해 App.js 파일의 경로를 paintId에서 paintCode로 수정하였다.
