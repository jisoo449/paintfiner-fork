## 시도한 해결책
![Image](https://github.com/user-attachments/assets/333a2acb-d325-403a-bb04-2eaa67a71fea)  
amplify에서 redirect&rewrite로 들어가 source에 *, target에 사용자 지정 도메인 입력

그럼에도 serverless 뭐시깽이로 리다이렉트됨.  
카카오 리다이렉트 url을 프론트에서 설정했기 때문
```
import { KAKAO_AUTH_URL } from "../../constants/kakao_auth_url.constants";
import styles from "./Auth.module.css";

export default function OAuthJoinButton(){

    const onClickKakaoJoin = (e) => {
        window.location.href=KAKAO_AUTH_URL;
    }; 

    return(
        <div className={styles.oauthbtn_wrapper}>
            <img src="/button/kakao_join_medium_narrow.png" onClick={onClickKakaoJoin}/>
        </div>
    );
}

-------------------------
const CLIENT_ID = process.env.REACT_APP_REST_API_KEY;
const REDIRECT_URI = process.env.REACT_APP_REDIRECT_URL;

export const KAKAO_AUTH_URL = `https://kauth.kakao.com/oauth/authorize?client_id=${CLIENT_ID}&redirect_uri=${REDIRECT_URI}&response_type=code`;
```
저기의 redirect_uri는 로컬의 .env 파일에 있음.  
Amplify의 환경변수로 설정해주자  

![Image](https://github.com/user-attachments/assets/eedfe738-e2fb-4444-a1d3-b5ed42311ca9)  
Amplify > 앱 선택 > 호스팅 > 환경변수  선택해서 redirecturl 수정하면 됨
