## 본문

## 문제 상세 설명
![image](https://github.com/paint-finder/webui/assets/48276691/954ee42e-f318-4123-8610-40fac2f90af7)  
```
ERROR: failed to solve: process "/bin/sh -c npm ci --only=production" did not complete successfully: exit code: 1
```   
Docker 파일 생성 후 해당 파일을 통해 도커 이미지를 생성할 때 `RUN npm ci --only=production`를 실행하는 도중 에러가 발생했다.  
<br/>
에러 메시지를 상세히 살펴보면 다음과 같은 문구를 볼 수 있다.  

```
npm error `npm ci` can only install packages when your package.json and package-lock.json or npm-shrinkwrap.json are in sync. Please update your lock file with `npm install` before continuing.
```    
즉, package.json, package-lock.json, npm-shrinkwrap.json이 일치하지 않아 발생한 문제이다. npm install을 통해 일치시켜야 한다.

## 시도한 해결책
- `npm install --package-lock-only` 를 입력해 package-lock.json 업데이트  
   참고: https://stackoverflow.com/questions/59984863/how-to-align-package-json-and-package-lock-json-when-dependency-versions-are-out  
- 이외의 방법으로는 package-lock.json을 삭제하고 npm install을 실행해 해당 json 파일을 재설치하는 방법이 있다.

## 해결
이를 해결하기 위해서는 다음과 같은  작업을 통해 디스크 공간을 확보해야 한다.  
### 1. 도커 시스템 청소
불필요한 이미지, 컨테이너, 네트워크 등을 삭제하여 디스크 공간을 확보한다.  
아래 명령어는 ec2 인스턴스에서 실행하라.
```
docker container prune -f
docker image prune -a -f
docker network prune -f
docker system prune -a -f
```
### 2. 도커 빌드 캐시 최소화
Dockerfile에서 불필요한 파일을 빌드 컨텍스트에 포함하지 않도록 .dockerignore 파일을 설정
```
node_modules
npm-debug.log
Dockerfile
.dockerignore
```
