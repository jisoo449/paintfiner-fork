## 설명
리액트 훅은 커스텀 훅 혹은 컴포넌트 내에서만 호출이 가능하다. 하지만 내가  작성한 코드를 살펴보면 리액트 외부에 선언된 함수에서 리액트 훅을 사용하는  것을 볼 수 있다.  
```
export const setupInterceptors = (apiInstance) => {
  apiInstance.interceptors.request.use(
    (config) => {
      const accessToken = useRecoilValue(accessTokenState); // 이 줄이 컴포넌트나 커스텀 훅 내부에서만 사용될 수 있습니다.
      if (accessToken) {
        config.headers.Authorization = `Bearer ${accessToken}`;
      }
      return config;
    },
    (error) => Promise.reject(error)
  );
};
```
이를 해결하려면 방법이 하나밖에 없다. 쿠키에 저장하거나, access token 값을 파라미터로 받는 것이다.
