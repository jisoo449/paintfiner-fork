## 본문

## 문제 상세 설명
다음과 같이 도커파일을 만들고 도커 이미지를 생성하였다.  
```
# Step 1: 리액트 애플리케이션 빌드
From node:20 AS build

#앱 디렉토리 생성
WORKDIR /app

#앱 의존성 설치
#가능한 경우(npm@5+) package.json과 package-lock.json을 모두 복사하기 위해 와일드카드를 사용
COPY package*.json ./
#RUN npm install
#프로덕션을 위한 코드를 빌드하는 경우
RUN npm ci --only=production 

#앱 소스 추가
COPY . .

# 리액트 애플리케이션 빌드
RUN npm run build

# Step 2: Nginx 설정 및 빌드된 리액트 애플리케이션 파일 복사(serve)
FROM nginx:alpine

# Copy the built React files from the previous step
COPY --from=build /app/build /usr/share/nginx/html

# Copy the Nginx configuration file
COPY nginx.conf /etc/nginx/conf.d/default.conf

# 3000 vs 80
EXPOSE 80

#CMD ["npm", "start"]
# nginx 서버 실행
CMD ["nginx", "-g", "daemon off;"]
```  
이후 도커 이미지를 실행하였으나, 접속이 불가하였다.


## 성공한 해결책
이는 도커 이미지파일을 실행할 때 포트 매핑을 하지 않아서 발생한 문제였다. 다음과 같은 명령어를 사용해 도커 이미지를 실행해야 한다.  
```
docker run -d -p 80:80 도커이미지이름
```
