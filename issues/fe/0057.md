## 설명
![image](https://github.com/paint-finder/webui/assets/48276691/7a3a7a70-b09d-493a-ad40-641c2554ee5f)
paintfinder.art 페이지에서 로그인 진행 시 로그인 핸들러 페이지로의 접근이 불가능했다.  
원격 저장소에 저장된 이미지를 pull 하여 run 한 결과가 동일한 것으로 보아 docker build 과정에서 문제가 발생한 것으로 추정된다. 

## 시도한 방법
- ~~.dockerignore 파일 삭제~~ -> 효과 없음
- ~~로그인 핸들러 페이지에 연결된 모든 함수 삭제~~ -> 효과 없음
- ~~로그인 핸들러 컴포넌트 이름과 파일 이름 다르게 함~~ -> 효과 없음
- 로그인핸들러 페이지 경로 수정 -> 성공

## 설명
다음의 원인이 예상된다.
- Nginx 설정에서 try_files 지시어 문제: try_files 지시어가 올바르게 설정되지 않아 특정 경로가 올바르게 처리되지 않을 수 있음
- 경로 구문 분석 문제: Nginx가 특정 경로를 구문 분석할 때 문제가 발생할 수 있다. 특히, /callback과 같은 경로가 API 엔드포인트와 혼동될 수 있다.
- 정적 파일과의 충돌: 경로가 특정 정적 파일 경로와 충돌할 수 있다.

하지만 위 방법으로 해결하지 못해 path 하나만 만들었다.
