## 문제 상세 설명
백엔드와 프론트엔드 통신을 통해 회원가입 진행 시
    No 'Access-Control-Allow-Origin' header is present on the requested resource.
위와 같은 에러가 뜨는 것을 확인했다.
html은 200을 리턴했기에 서버와의 통신에 있어서 문제되는 부분은 아닌 것을 확인했다.

구글링 결과 자바 스크립트에 있는 Same-Origin Policy 라는 보안 규칙에 의한 문제이다.
자바 스크립트로 다른 웹페이지에 접근 시 같은 출처 - 프로토콜, 호스트명, 포트 - 의 페이지에만 접근이 가능하다.

## 해결책
>프록시 서버를 생성해 해결
1. 프록시 미들웨어 라이브러리 설치
```
npm install http-proxy-middleware
```
2. src에 생성된 setupProxy.js 파일 편집
```
const { createProxyMiddleware } = require('http-proxy-middleware');
module.exports = function(app) {
  app.use(
    '/실행할 패스',
    createProxyMiddleware({
      target: '처리할 URL',
      changeOrigin: true,
    })
  );
};
```
3. 패스 경로에 매핑된 URL 생략하고 적어주기
```
axios.post("/실행할 패스",null,{. . .}).then(res=>{. . .}).catch(error=>{. . .});
```
