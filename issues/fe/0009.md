### jisoo449 (2023-06-26T05:50:17Z)

api단과 component단에서 수정을 하여 문제를 해결하였다. 

1. api단
<pre>
<code>
    export default async function getPaintDetail(paintId, success, err){
        return await api.get('/paint/get_paint?', {params:{'idx_pk':paintId}}).then(success).catch(err);
    }
</code>
</pre>
비동기 함수에서 .then(success)를 쓰지 않으면 데이터에 접근이 불가능하다. 따라서 값을 받아오고 싶다면 .then(success)를 써주어야 한다.

2. component단
<code>const [paint,setPaint] = useState({});</code>
받아오는 데이터의 타입에 따라 useEffect를 초기화해주어야 한다. 여기서 받아오는 patin의 타입은 Object이므로 {}로 선언을 해 주었다.
