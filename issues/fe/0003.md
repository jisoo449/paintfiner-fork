## 문제 상세 설명
api를 분리하는 과정에서 문제 발생
불러온 api를 useEffect 함수 안에 넣고 페이지 렌더링과 동시에 api를 실행시키려 하였으나 아래와 같은 에러가 발생
```
React Hook "useApi" cannot be called inside a callback. React Hooks must be called in a React function component or a custom React Hook function  react-hooks/rules-of-hooks
```

## 해결 방법
useEffect 안에 바로 axios.get을 사용했더니 다음과 같은 에러 메세지가 나왔다.
'''
Warning: useEffect must not return anything besides a function,
which is used for clean-up.
It looks like you wrote useEffect(async () => ...) or returned a Promise.
Instead, write the async function inside your effect and call it immediately:
useEffect(() => {
  async function fetchData() {
    // You can await here
    const response = await MyAPI.getData(someId);
    // ...
  }
  fetchData();
}, [someId]); // Or [] if effect doesn't need props or state
'''
이를 참고하여 api에도 async, useEffect 내에도 async를 선언하였더니 성공하였다.
