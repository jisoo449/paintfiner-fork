### jisoo449 (2024-06-09T06:28:38Z)

curl 명령어를 사용하여 healt check 경로를 검사하였더니 다음과 같은 결과가 나왔다. 
```
# curl -I http://paintfinder.art/

HTTP/1.1 301 Moved Permanently
Server: awselb/2.0
Date: Sun, 09 Jun 2024 06:23:45 GMT
Content-Type: text/html
Content-Length: 134
Connection: keep-alive
Location: https://paintfinder.art:443/
```
위 결과는 `http://paintfinder.art/`로 요청한 리소스가 `https://paintfinder.art/`로 리디렉션 되고 있음을 의미한다.  
이를 위해 http 헬스 체크가 https로 리디렉션 되지 않도록 /health 경로를 생성하고 200을 응답하도록 코드를 수정하였다.
