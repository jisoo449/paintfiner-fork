## 본문

react 에서 drag and drop 기능으로 두 가지 라이브러리를 사용한다는 것을 파악.

- react-dnd : 광범위한 기능, 자율적인 커스텀 가능, 원하는 기능 찾아 적용하기 어려울 수 있음
- react-beautiful-dnd : 한정된 기능, 한정된 커스텀 기능, 조금 더 쉬운 구현

목록 내에서 drag and drop을 할 생각이라, 다양한 기능이 필요하지 않다고 판단, 애니메이션이 깔끔하고, 구현 난이도가 (비교적) 쉬운 편인 `react-beautiful-dnd` 를 사용하기로 결정.
