## 본문

sizes : 화면에 보여줄 사이즈 목록을 문자열로 저장한 것. 구분자는 ',' (컴마) 로 한다.
size : 각 사이즈별로 다 저장한다.(크롤러에서 나눠 저장하던, spring 에서 파싱하던 자유)
    ml, g 만 사용. oz 는 x30 해서 ml로 저장
unit : size 에 맞는 단위를 저장. (ml, g, halfpan, pot)
