## 댓글

### pch8349 (2023-08-04T06:40:51Z)

python version을 3.7.4로 downgrade 한 후 실행하려 하니
ipykernel이 필요해짐.

ipykernel을 pip, vsc 설치 방식 모두 진행해보았으나 에러 발생.

다음 과정을 거쳐서 설치 완료함
pip install psutil --only-binary :all:    -> psutil 패키지가 설치가 안되어 미리 컴파일된 바이너리를 설치
pip install wheel    -> 파이썬 패키지를 바이너리 형태로 패키징 하는 도구
pip install ipykernel   
pip install -U cython   -> 아래 3개는 psutil 의존성 패키지
pip install -U cpython
pip install psutil
