## 설명
[pigment database 사이트](https://www.artiscreation.com/)를 크롤링 할 수 없는 문제 발생.  
위 사이트를 크롤링하면 다음과 같은 soup가 반환된다.
``` html
<head>
  <title>Not Acceptable!</title>
</head>
<body>
  <h1>Not Acceptable!</h1>
  <p>An appropriate representation of the requested resource could not be found on this server. This error was generated by Mod_Security.</p>
</body>
```
이는 서버 상에서 Mod_security라는 보안 모듈이 요청을 거부하여 생기는 반환값이다.  
이를 해결할 방법을 찾지 못하여서 모든 페이지에 들어가서 각각의 요소들을 copy하여 문자열로 붙여넣기하고, 그 문자열에서 파싱을 진행하였다.
